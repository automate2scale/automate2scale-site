# automate2scale.io

Marketing site for Automate2Scale: the A³ Revenue Operating System.

- Single static page: `index.html` (hash routes: #system, #journey, #crm, #scorecard, #session, #about)
- Hosted on Netlify, auto-deploys on every push to `main`
- Booking popup loads the GHL calendar at link.automate2scale.io
